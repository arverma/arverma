I am **Aman Ranjan Verma**, a **Senior Data Engineer** at [**QuillBot**](https://www.linkedin.com/company/quillbot) with **7+ years** of experience building production-grade data platforms and pipelines (ex-**Flipkart**, ex-**Sigmoid**).
